# Acme 平台 FAQ 卡（範例）

footnote 的 FAQ 卡範例。每張卡回答一個問題，frontmatter 列出問法與出處，本文每句事實標 `[n]` 對應 `sources`。
`glossary.yaml` 是別名詞彙表。格式與規則見 [`docs/faq-rules.md`](../../docs/faq-rules.md)；用 `footnote faq lint --check-sources` 檢查。

第一次用 `make import-examples`（等於 `footnote faq import examples/faq`）寫進資料庫，只能做一次，之後的修改走提案。

這個 README 不會被索引。內容是虛構的。
